# API-тестирование (API Testing)

Данный навык верифицирует функциональность, стабильность и безопасность интерфейсов API.

## Чек-лист проверок эндпоинта
1. **Позитивные сценарии (2xx)**:
   - Корректность статус-кода (`200 OK`, `201 Created`, `204 No Content`).
   - Соответствие тела ответа JSON-схеме (типы данных, обязательные поля).
2. **Негативные сценарии (4xx / 5xx)**:
   - Невалидные типы полей -> `400 Bad Request`.
   - Отсутствие авторизации -> `401 Unauthorized`.
   - Доступ к чужому ресурсу -> `403 Forbidden`.
   - Несуществующий ID -> `404 Not Found`.
