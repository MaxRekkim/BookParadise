# Аутентификация и авторизация (Auth & Access Control)

Данный навык обеспечивает безопасность учетных записей и разграничение прав доступа.

## Архитектура аутентификации
1. **Хранение секретов**:
   - Хеширование паролей алгоритмами Argon2id или bcrypt с солью.
   - Хранение токенов на клиенте в системных защищенных хранилищах (Keychain на iOS/macOS, Keystore на Android).
2. **Модель JWT токенов**:
   - Короткоживущий Access Token (15–60 мин) + долгоживущий Refresh Token с ротацией при каждом обновлении.
3. **Разграничение доступа (RBAC / ABAC)**:
   - Проверка прав на каждом защищенном эндпоинте: роль (Admin, User, Guest) и владение ресурсом.
