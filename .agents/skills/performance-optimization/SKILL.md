# Оптимизация производительности (Performance Optimization)

Данный навык делает приложение быстрым, отзывчивым и экономным к системным ресурсам.

## Правило №1
*Не оптимизируй без измерений (No premature optimization).*

## Основные направления оптимизации
1. **Рендеринг и UI**:
   - Минимизация инвалидации представлений в SwiftUI/Flutter.
   - Ленивая загрузка списков (`LazyVStack`, `ListView.builder`).
   - Кэширование декодированных изображений нужного разрешения.
2. **Сложность алгоритмов**:
   - Замена квадратичных поисков O(N^2) на хэш-таблицы O(1) или бинарный поиск O(log N).
3. **Кэширование**:
   - Многоуровневый кэш: Memory Cache (In-Memory) -> Disk Cache -> Remote.
