# Работа с зависимостями (Dependency Management)

Данный навык защищает проект от атак на цепочку поставок (Supply Chain Attacks) и конфликтов библиотек.

## Правила управления зависимостями
1. **Фиксация версий**:
   - Обязательное коммитирование lock-файлов (`Package.resolved`, `pubspec.lock`, `package-lock.json`).
2. **Минимизация зависимостей**:
   - Если задача решается 20 строками чистого стандартного кода, не тянуть внешнюю библиотеку.
3. **Регулярный аудит**:
   - Запуск `npm audit`, `cargo audit` или `dependabot` для выявления CVE в зависимостях.
