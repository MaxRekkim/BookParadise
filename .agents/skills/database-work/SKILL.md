# Работа с базами данных (Database Work)

Данный навык обеспечивает эффективное взаимодействие приложения с хранилищами данных.

## Правила работы с запросами
1. **Исключение проблемы N+1**:
   - Использование `JOIN` или eager loading (`include` / `preload`) вместо выборки в цикле.
2. **Минимизация передаваемых данных**:
   - Выбирать только необходимые поля вместо `SELECT *`.
   - Использовать пагинацию для больших наборов строк.
3. **Безопасность**:
   - Использовать исключительно параметризованные запросы или ORM для защиты от SQL-инъекций.
