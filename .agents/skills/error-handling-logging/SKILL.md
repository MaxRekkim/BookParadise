# Обработка ошибок и логирование (Error Handling & Logging)

Данный навык гарантирует прозрачность поведения системы и удобство диагностики инцидентов.

## Уровни логирования
- **DEBUG**: детальная отладочная информация в процессе разработки.
- **INFO**: ключевые бизнес-события (успешный логин, создание книги, старт сессии).
- **WARN**: нештатные ситуации, не прервавшие выполнение (ретрай запроса, устаревший кэш).
- **ERROR**: ошибки, приведшие к сбою операции (сбой парсинга, ошибка БД).
- **FATAL**: падение приложения / сервиса.

## Правила структурированных логов
- Логировать контекст: `timestamp`, `level`, `userId`, `action`, `traceId`.
- **Никогда не логировать**: пароли, токены, CVV, номера карт и персональные данные (PII).
