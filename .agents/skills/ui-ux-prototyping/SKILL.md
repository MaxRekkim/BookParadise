# Прототипирование UI/UX (UI/UX Prototyping)

Данный навык проектирует интуитивно понятные интерфейсы с акцентом на пользовательский путь и обработку всех состояний.

## 4 обязательных состояния экрана
1. **Loading State**: ненавязчивый индикатор загрузки, шиммеры/скелетоны вместо резких скачков верстки.
2. **Empty State**: дружелюбная иллюстрация, поясняющий текст и кнопка с призывом к первому действию (Call-to-Action).
3. **Error State**: понятное описание возникшей проблемы без технического жаргона + кнопка повтора («Попробовать снова»).
4. **Content State**: аккуратное отображение информации с соблюдением иерархии шрифтов и отступов.

## Принципы взаимодействия
- **Закон Фиттса**: ключевые интерактивные элементы легко достижимы пальцем (нижняя зона экрана на мобильных).
- **Мгновенная обратная связь**: анимации нажатия, тактильный отклик (haptics), подсветка фокуса.
