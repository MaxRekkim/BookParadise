# Деплой и облачные сервисы (Deployment & Cloud)

Данный навык управляет выкатыванием приложений в продакшн без простоев (Zero-Downtime).

## Стратегии деплоя
1. **Rolling Update**: постепенная замена старых инстансов новыми.
2. **Blue-Green Deployment**: наличие двух идентичных окружений, моментальное переключение трафика через балансировщик.
3. **Canary Releases**: отправка 5–10% трафика на новую версию для проверки стабильности на реальных пользователях.
4. **Health Checks**: наличие рабочих эндпоинтов `/healthz` и `/ready` для оркестраторов.
