# Техники тест-дизайна (Test Design Techniques)

Данный навык позволяет достичь максимального покрытия качества при минимальном количестве тестов.

## Основные техники
1. **Классы эквивалентности (Equivalence Partitioning)**:
   - Разделение входных данных на группы, где система ведет себя одинаково (выбираем 1 представителя из каждого класса).
2. **Анализ граничных значений (Boundary Value Analysis)**:
   - Тестирование границ диапазонов (Min - 1, Min, Min + 1, Max - 1, Max, Max + 1).
3. **Таблицы решений (Decision Tables)**:
   - Матрица сложных комбинаций условий и соответствующих действий системы.
4. **Тестирование перехода состояний (State Transition)**:
   - Проверка допустимых и недопустимых переходов между статусами сущности (например, книга: `reading` -> `read`).
