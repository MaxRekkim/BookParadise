# Тестирование доступности (Accessibility / a11y)

Данный навык гарантирует доступность приложения для людей с ограниченными возможностями здоровья.

## Ключевые требования
1. **Поддержка Screen Readers (VoiceOver / TalkBack)**:
   - Все иконки и кнопки имеют понятный `accessibilityLabel` (не «Image_01», а «Добавить книгу в библиотеку»).
2. **Контрастность текста**:
   - Минимальный коэффициент контрастности текста к фону 4.5:1 (для обычного текста) по стандарту WCAG AA.
3. **Dynamic Type**:
   - Интерфейс корректно перестраивается и не обрезает текст при увеличении шрифта в настройках ОС.
4. **Минимальный размер кликабельной области**:
   - Не менее 44x44 pt для комфортного тапа пальцем.
