# Написание баг-репортов (Bug Reporting)

Данный навык документирует дефекты так, чтобы разработчик мог воспроизвести и устранить их с первого раза.

## Структура идеального баг-репорта
- **Заголовок**: `[Компонент] Краткое описание дефекта при конкретном действии`.
- **Окружение**: Версия приложения, ОС, устройство.
- **Предусловия**: начальное состояние.
- **Шаги воспроизведения (1, 2, 3...)**: предельно точные действия.
- **Фактический результат**: что произошло на самом деле (+ стек-трейс / лог).
- **Ожидаемый результат**: как система должна была себя повести по спецификации.
- **Критичность**: Blocker / Critical / Major / Minor.
