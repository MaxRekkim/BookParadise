# Анализ логов и метрик (Logs & Metrics Analysis)

Данный навык извлекает практические инсайты из потоков телеметрии и логов.

## Задачи анализа
- Поиск аномальных всплесков ошибок (`error rate spike`).
- Анализ распределения задержек (p50, p90, p99).
- Корреляция логов между клиентом и сервером по сквозному `Trace-ID`.
- Выявление утечек ресурсов по графикам потребления памяти и CPU во времени.
