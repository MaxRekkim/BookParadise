# Интеграционное тестирование (Integration Testing)

Данный навык верифицирует корректность совместной работы изолированных модулей.

## Фокус проверки
1. **Взаимодействие с хранилищем**:
   - Сохранение сущности -> перезапуск менеджера -> чтение сущности из файла/БД.
2. **Сетевые адаптеры и парсинг**:
   - Передача мокового сетевого ответа в сервис -> проверка корректности маппинга в доменные модели.
3. **Очистка состояния (Clean Slate)**:
   - Каждый интеграционный тест обязан очищать созданные тестовые файлы или откатывать транзакции в БД.
