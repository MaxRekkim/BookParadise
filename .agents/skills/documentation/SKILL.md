# Написание документации (Documentation)

Данный навык формирует качественную, структурированную и актуальную документацию проекта.

## Модель Diátaxis (4 типа документации)
1. **Tutorials (Обучение)**: пошаговое руководство для новичка («Первый старт за 5 минут»).
2. **How-To Guides (Практические рецепты)**: решение конкретной прикладной задачи («Как подключить облачную синхронизацию»).
3. **Reference (Справочник)**: строгое описание API, форматов моделей, параметров конфигов.
4. **Explanation (Объяснение)**: архитектурные концепции, причины выбора того или иного решения (ADR).

## Требования к README.md
- Что делает проект (краткая суть).
- Скриншоты / демонстрация.
- Быстрый старт (требования, установка, запуск).
- Ссылки на релизы и документацию.
