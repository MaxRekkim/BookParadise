# Обратная связь и продуктовая аналитика (Feedback & Analytics)

Данный навык измеряет реальное поведение пользователей для принятия решений на основе данных.

## Структура аналитического события
```json
{
  "event": "reading_session_completed",
  "properties": {
    "book_id": "uuid-123",
    "pages_read": 24,
    "duration_seconds": 1800,
    "soundscape_active": true
  }
}
```

## A/B эксперименты
- Формулирование проверяемой гипотезы: «Включение Bionic Reading по умолчанию повысит среднее время чтения на 15%».
- Расчет размера выборки и статистической значимости (p-value < 0.05).
