# Тест-кейсы и чек-листы (Test Cases & Checklists)

Данный навык превращает требования в конкретные верификационные сценарии.

## Структура тест-кейса
- **ID & Title**: уникальный идентификатор и понятное название.
- **Предусловия (Preconditions)**: состояние системы, наличие авторизации, данные.
- **Шаги воспроизведения (Steps)**: нумерованный список четких действий.
- **Тестовые данные (Test Data)**: используемые входные значения.
- **Ожидаемый результат (Expected Result)**: точное и однозначно проверяемое состояние системы.
- **Постусловия (Postconditions)**: очистка созданных данных.
