# Разработка Frontend-кода (Frontend Development)

Данный навык создает отзывчивые, кроссплатформенные и реактивные интерфейсы (SwiftUI, Flutter, Web).

## Лучшие практики
1. **Однонаправленный поток данных (UDF)**:
   - State (состояние) порождает UI.
   - Действия пользователя (Intent/Action) отправляются в ViewModel/Store.
   - ViewModel обновляет State, вызывая реактивную перерисовку представления.
2. **Композиция компонентов**:
   - Разделение крупных монолитных экранов на мелкие переиспользуемые виджеты/компоненты.
3. **Адаптивность**:
   - Корректная поддержка портретной и альбомной ориентации, планшетов, десктопных окон.
   - Поддержка темного и светлого режимов (Dark / Light Mode).
