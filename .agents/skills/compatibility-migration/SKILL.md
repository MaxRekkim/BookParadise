# Тестирование совместимости и миграций (Compatibility & Migrations)

Данный навык гарантирует, что апгрейд приложения не сломает данные пользователя.

## Сценарии миграции
1. **Обновление «поверх»**:
   - Установка старой версии (например, v2.13.0) -> наполнение книгами, цитатами, заметками.
   - Накатывание новой версии (v3.0.0) -> проверка сохранения 100% записей.
2. **Миграция схем данных**:
   - Автоматическое добавление полей по умолчанию при загрузке старых JSON-файлов.
   - Отсутствие фатальных ошибок декодирования (`DecodingError.keyNotFound`).
