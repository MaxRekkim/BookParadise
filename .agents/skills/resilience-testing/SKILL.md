# Тестирование отказоустойчивости (Resilience Testing)

Данный навык проверяет жизнеспособность приложения в экстремальных и нестабильных условиях.

## Проверочные сценарии
- **Airplane Mode / No Network**: приложение продолжает открываться, читать сохраненные книги и показывать статистику.
- **Flaky Connection**: частые обрывы сети не приводят к падению фоновых процессов.
- **Low Memory Warning**: приложение корректно сбрасывает кэш картинок в памяти без краша.
- **Disk Full**: безопасная обработка невозможности записи файла с уведомлением пользователя.
