# Измерение покрытия кода (Code Coverage)

Данный навык оценивает полноту тестирования исходного кода проекта.

## Метрики покрытия
- **Line Coverage**: процент строк, исполненных в ходе тестов.
- **Branch Coverage**: проверка всех ветвей условных операторов (`if/else`, `switch`).

## Стандарты качества
- **Бизнес-логика и сервисы**: целевое покрытие > 85%.
- **Модели и парсеры**: целевое покрытие > 90%.
- Не стремиться к 100% ради красивой цифры: покрывать реальные риски, а не тривиальные геттеры и сеттеры.
