# Code Review

Данный навык проводит глубокий и конструктивный анализ предложенных изменений в коде.

## Чек-лист ревьюера
1. **Логика и корректность**:
   - Решает ли данный PR поставленную задачу?
   - Обработаны ли граничные условия (null, пустой список, сетевая ошибка)?
2. **Архитектура и стиль**:
   - Соответствует ли код принятым паттернам проекта?
   - Нет ли дублирования существующего функционала?
3. **Производительность и память**:
   - Нет ли циклических ссылок (`retain cycles`, отсутствие `weak self`)?
   - Нет ли блокировок главного потока (Main Thread)?
4. **Тесты и документация**:
   - Покрыт ли новый функционал тестами?
   - Обновлен ли CHANGELOG?
