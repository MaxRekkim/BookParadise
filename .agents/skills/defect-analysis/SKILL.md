# Анализ дефектов и RCA (Defect Analysis)

Данный навык устраняет первопричины ошибок, а не только их внешние симптомы.

## Метод «5 Почему» (5 Whys)
1. *Почему упало приложение?* — Разрезыменирован nil при чтении сессий.
2. *Почему там был nil?* — Метод обратился к свойству `sessions`, которого не было.
3. *Почему свойства не было?* — В сервисе оно называлось `sessionHistory`.
4. *Почему компилятор пропустил это на локальной проверке?* — Локальная проверка запускалась без контекста всего таргета.
5. *Системное исправление*: добавить alias `sessions` и настроить обязательную валидацию схемы перед коммитом.
