# Проектирование схемы БД (Database Schema Design)

Данный навык создает надежные, нормализованные и производительные структуры хранения данных.

## Процедура проектирования
1. **Моделирование сущностей (ERD)**:
   - Выявление сущностей, их атрибутов и уникальных первичных ключей (UUID/BigInt).
   - Определение связей: один-к-одному (1:1), один-ко-многим (1:N), многие-ко-многим (N:M через связующую таблицу).
2. **Нормализация и денормализация**:
   - Приведение схемы к 3-й нормальной форме (3NF) для исключения дублирования.
   - Осознанная денормализация при требованиях к высокой скорости чтения (read-heavy нагрузки).
3. **Индексы и ограничения**:
   - Определение уникальных (UNIQUE), внешних (FOREIGN KEY) и проверочных (CHECK) ограничений.
   - Индексирование полей, участвующих в WHERE, JOIN, ORDER BY.
   - Создание составных индексов с учетом селективности колонок.
4. **Миграции**:
   - Разделение DDL на идемпотентные шаги с возможностью отката (Up / Down).
