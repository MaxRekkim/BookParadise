# Безопасное программирование (Secure Coding)

Данный навык обеспечивает защиту данных пользователя и предотвращает эксплуатацию уязвимостей.

## Золотые правила безопасности
1. **Принцип наименьших привилегий (PoLP)**:
   - Запрашивать у пользователя только строго необходимые разрешения (доступ к файлам, камере, уведомлениям).
2. **Валидация всего входящего ввода**:
   - Не доверять никаким входящим данным от пользователя или сети (Sanitization, Validation).
3. **Защита от утечки секретов**:
   - Никаких захардкоженных API ключей в исходном коде.
   - Использование `.gitignore` и сканеров секретов (trufflehog, gitleaks).
