# Настройка CI/CD (Continuous Integration & Delivery)

Данный навык автоматизирует проверку кода, сборку бинарников и доставку релизов на всех целевых платформах.

## Структура идеального пайплайна
1. **Lint & Static Analysis**: быстрая проверка синтаксиса и стиля.
2. **Automated Tests**: параллельный прогон юнит- и интеграционных тестов.
3. **Matrix Build**: параллельная сборка под все платформы (iOS, macOS, Android, Windows, Linux).
4. **Artifact Packaging & Signing**: генерация дистрибутивов (`.ipa`, `.dmg`, `.apk`, `.zip`).
5. **Release Distribution**: автоматическое создание GitHub Release, обновление манифестов и загрузка артефактов.
