# Проектирование архитектуры (Architecture Design)

Данный навык проектирует устойчивую, масштабируемую и тестируемую структуру программного решения.

## Ключевые архитектурные паттерны
1. **Clean Architecture / Hexagonal**:
   - **Domain (Core)**: модели сущностей и чистая бизнес-логика без внешних зависимостей.
   - **Use Cases / Interactors**: сценарии взаимодействия приложения.
   - **Interfaces / Adapters**: репозитории, ViewModels, контроллеры.
   - **Infrastructure**: UI фреймворки (SwiftUI, Flutter, React), БД, сетевые клиенты.
2. **Принцип инверсии зависимостей (Dependency Inversion)**:
   - Высокоуровневые модули зависят от абстракций (протоколов/интерфейсов), а не от конкретных реализаций.
3. **Модульность**:
   - Определение четких контрактов между слоями.
   - Изоляция состояния и однонаправленный поток данных (Unidirectional Data Flow).

## Чек-лист архитектурного ревью
- [ ] Отсутствуют циклические зависимости между модулями.
- [ ] Бизнес-логика независима от UI-фреймворка и сторонних библиотек.
- [ ] Легко подменять источники данных для юнит-тестов (Mocks/Stubs).
