# Проектирование API (API Design)

Данный навык создает предсказуемые, безопасные и стандартизированные контракты межсервисного и клиент-серверного взаимодействия.

## Стандарты RESTful API
1. **Ресурсно-ориентированные URI**:
   - Существительные во множественном числе: `/api/v1/books`, `/api/v1/books/{id}/quotes`.
2. **HTTP-методы и идемпотентность**:
   - `GET`: чтение данных (идемпотентный, безопасный).
   - `POST`: создание нового ресурса.
   - `PUT`: полная замена ресурса (идемпотентный).
   - `PATCH`: частичное обновление (идемпотентный).
   - `DELETE`: удаление ресурса (идемпотентный).
3. **Единый формат ответа**:
   ```json
   {
     "success": true,
     "data": { ... },
     "meta": { "page": 1, "total": 100 },
     "error": null
   }
   ```
4. **Пагинация, сортировка и фильтрация**:
   - Cursor-based или offset/limit пагинация (`?limit=20&cursor=eyJ...`).
   - Сортировка: `?sort=-createdAt,title`.
