# Регрессионное тестирование (Regression Testing)

Данный навык гарантирует стабильность и целостность проекта при выпуске каждого обновления.

## Стратегия регресса
1. **Smoke Suite (Дымовой прогон)**:
   - Топ-10 критических путей приложения, запускаемых на каждый коммит/PR.
2. **Full Regression Suite**:
   - Полный прогон всех функциональных тестов перед релизом новой версии (например, перед тегом v3.0.0).
3. **Автоматизация**:
   - Включение регрессионного набора в CI/CD пайплайн.
