# Тестирование безопасности (Security Testing)

Данный навык проводит аудит защищенности приложения от атак и утечек.

## Чек-лист безопасности
1. **Аудит сетевого слоя**:
   - Принудительное использование HTTPS/TLS.
   - Отсутствие передачи токенов и паролей в URL query parameters.
2. **Хранение данных на устройстве**:
   - Шифрование локальных баз данных и файлов.
   - Проверка, что чувствительные данные не сохраняются в незашифрованном `UserDefaults` или файлах бэкапа.
3. **Защита от инъекций**:
   - Проверка полей ввода на SQL-инъекции, XSS и Path Traversal (`../../etc/passwd`).
