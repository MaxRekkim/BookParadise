# Интеграция внешних API (External Integrations)

Данный навык строит отказоустойчивые адаптеры для работы со сторонними сервисами и API.

## Паттерны надежности
1. **Таймауты (Timeouts)**:
   - Каждый сетевой запрос обязан иметь жесткий лимит времени (connect timeout 5s, read timeout 15s).
2. **Экспоненциальный откат (Exponential Backoff & Jitter)**:
   - Повторные попытки при временных ошибках (5xx, 429) с прогрессирующей задержкой + случайное смещение (jitter).
3. **Предохранитель (Circuit Breaker)**:
   - Временная блокировка запросов к упавшему внешнему сервису для предотвращения каскадного падения своего приложения.
4. **Изоляция секретов**:
   - API-токены и приватные ключи читаются исключительно из защищенного хранилища / переменных окружения.
