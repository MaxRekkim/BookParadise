# Работа с файлами и потоками данных (File & Data Processing)

Данный навык обеспечивает безопасную и производительную работу с файлами и конвертацией форматов.

## Принципы потоковой обработки
1. **Потоковое чтение (Streaming / Chunks)**:
   - Чтение больших файлов порциями (chunks), избегая загрузки всего объема в оперативную память.
2. **Валидация при загрузке**:
   - Проверка MIME-типа и магических байтов (Magic Bytes) файла, а не только расширения.
   - Ограничение максимального размера загружаемого файла.
3. **Очистка ресурсов**:
   - Гарантированное закрытие файловых дескрипторов и удаление временных файлов в блоках `defer` / `finally`.
