# История изменений (Changelog) — «Книжный Рай»

Все заметные изменения в проекте «Книжный Рай» документируются в этом файле.
Формат основан на принципах [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и следует спецификации [Семантического версионирования (SemVer)](https://semver.org/lang/ru/):
- **MAJOR (`3.0.0`)**: Глобальные архитектурные обновления и масштабный редизайн.
- **MINOR (`2.1.0`)**: Добавление новых экранов и функций без нарушения совместимости.
- **PATCH (`2.0.1`)**: Исправление багов, дефектов верстки и патчи безопасности.
- **ПРЕ-РЕЛИЗЫ (Alpha / Beta / RC)**:
  - **`X.Y.Z-alpha.N` (например, `2.1.0-alpha.1`)**: Ранние сборки с экспериментальными фичами для внутреннего тестирования.
  - **`X.Y.Z-beta.N` (например, `2.1.0-beta.1`)**: Готовые для тестирования сборки (на GitHub помечаются оранжевым бейджем *Pre-release*).
  - **`X.Y.Z-rc.N` (например, `2.1.0-rc.1`)**: Release Candidate — кандидат в стабильный релиз после успешного бета-тестирования.

## [2.0.0] — 2026-10-15

### 🚀 Главные нововведения

#### 🎨 Полный редизайн и адаптивный интерфейс macOS
- **Настольный трехуровневый сайдбар (`NavigationSplitView`)**:
  - Закреплено поведение видимости (`columnVisibility = .all` со стилем `.balanced`). Сайдбар больше не схлопывается самопроизвольно при ресайзе окна.
  - Добавлена стандартная кнопка переключения сайдбара с иконкой `sidebar.leading` в верхний тулбар.
  - Назначен системный шорткат **⌘ + S** для мгновенного скрытия/отображения бокового меню.
  - Зафиксирована удобная ширина сайдбара (220–320 pt).
- **Пакетная дистрибуция для macOS**:
  - Создание образа диска **`BookParadise-2.0.0.dmg`** с функцией Drag-and-Drop в `/Applications`.
  - Сборка официального установщика пакетов **`BookParadise-2.0.0.pkg`**.
  - Формирование портативного архива **`BookParadise-2.0.0-macOS.zip`**.

#### 📊 Глубокая аналитика и статистика (`DetailedStatsView`)
- **Предиктивный трекер годовой цели 2026**:
  - Интерактивный расчет темпа: математическое сравнение фактического количества прочитанных книг с расчетным графиком года (день из 365).
  - Уведомления об опережении или отставании с расчетом нужного темпа страниц/день для успешного завершения цели.
- **Интерактивные метрики Дашборда**:
  - Карточки «В библиотеке», «Прочитано», «В очереди» и «Темп чтения» стали кликабельными с переходом к детальному анализу.
  - Добавлен баннер быстрого перехода к полной аналитике прямо с главного экрана.
- **Глубокий срез по форматам (Бумажные vs Электронные)**:
  - Двухцветная диаграмма соотношения, средний объем книги в каждом формате, количество страниц.
- **Аналитика по всем 9 жанрам**:
  - Прогресс-бары прочитанных книг по каждому жанру с цветной кодировкой.
- **Золотая полка «Шедевры»**:
  - Отдельная витрина книг, отмеченных читателем высшей оценкой «Шедевр!».
- **Лог сессий чтения**:
  - История завершенных сессий с таймером Помодоро: дата, затраченное время, прирост страниц и средняя скорость (стр./час).

#### 📚 Встроенное хранилище электронных книг и читалка
- Поддержка добавления и чтения локальных файлов `.pdf`, `.epub`, `.fb2`, `.txt` прямо в приложении на iOS и Mac.
- Просмотр объема файла и встроенный просмотрщик `QuickLook` (`QLPreviewController`).

### 🐛 Исправления ошибок (Bug Fixes)

- **Критический баг с зависанием окна цитаты (`QuoteCardShareView`)**:
  - Устранена блокировка модального окна при нажатии кнопки «Готово» путем передачи прямого замыкания `onDismiss` для сброса состояния родительского контроллера.
  - Устранен сбой в Mac Catalyst при нажатии «Поделиться карточкой»: устаревший `UIActivityViewController` заменен на нативные действия:
    - **«Скопировать открытку (PNG)»** напрямую в системный буфер обмена (`UIPasteboard.general.image`).
    - Нативный SwiftUI **`ShareLink`** без создания лишних модальных слоев.
    - Кнопка **«Сохранить фото в галерею»**.
- **Исправление кликабельности элементов на Mac**:
  - Исправлено поведение кнопок обложек и списков на macOS Catalyst добавлением `.buttonStyle(.plain)` и `.contentShape(Rectangle())`.
  - Устранены ошибки компиляции `init(selection:content:)` в `MainTabView.swift`.
- **Исправление отображения даты цитат**:
  - Заменено отсутствующее поле `quote.createdAt` на актуальное `quote.dateAdded`.
- **Совместимость с iOS 16**:
  - Исправлена сигнатура модификатора `.fileImporter` с явным указанием `[UTType]`.

### 🛡️ Безопасность и защита данных (Security & Pentest Hardening)

- **App Transport Security (ATS)**:
  - В `Info.plist` отключен опасный глобальный флаг `NSAllowsArbitraryLoads`. Весь сетевой трафик приложения переведен исключительно на HTTPS (TLS 1.3).
- **Защита от Path Traversal**:
  - В `EBookStorageManager.swift` внедрена жесткая санитизация имен сохраняемых книг: блокировка любых спецсимволов и попыток обхода директорий (`../`).
- **Аппаратное шифрование данных (Data Protection)**:
  - Запись локального кэша библиотеки (`BookParadiseCache.json`), очереди отложенных действий, истории сессий и цитат теперь выполняется с флагом `[.atomic, .completeFileProtection]` (шифрование ключом Secure Enclave в заблокированном состоянии устройства).
- **Оптимизация iCloud Backup**:
  - Папка с электронными книгами помечена атрибутом `isExcludedFromBackup = true`, предотвращая переполнение квоты резервной копии пользователя тяжелыми PDF/EPUB.
- **Валидация Google Apps Script Web App**:
  - Запрещены небезопасные HTTP-соединения для синхронизации с Google Таблицей — разрешен только защищенный протокол `https://script.google.com/...`.
